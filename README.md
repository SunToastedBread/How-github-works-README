You can upload your work there so others can help you with it by collaborating with you and editing your files or fixing bugs and errors found by its users.
They can also fork your project so they can make their own version of it, which can be a different theme, added features, or whatever they want in their version of the main forked project under their account.
GitHub also has many useful features, like Git which lets you push your work from VScode directly to a branch on your Github repo.
It also has community features which let projects be found by more people which helps you improve your project by getting collaborators from all across the world.
Pulling is also a feature which lets you get someones project via terminal onto your pc, so you can use it or just download the full .zip of their source code, works eiher way and the same way.
